# rtMedia for WordPress, BuddyPress and bbPress Stubs

rtMedia for WordPress, BuddyPress and bbPress stubs for static analysis (PHPStan, Psalm, IDEs), generated by
[stub-forge](https://github.com/Pink-Crab/stub-forge) with
[php-stubs/generator](https://github.com/php-stubs/generator).
Includes private and protected members. Each git tag matches the plugin
version the stubs were generated from.

## Installation

```
composer require --dev pinkcrab/rtmedia_stubs:4.7.11
```

## Regenerating

Place the plugin source in `source/rtMedia/`, then run `./generate.sh`.
